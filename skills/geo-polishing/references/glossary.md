# Chinese → English glossary for remote sensing and GIS

Use the English term in the second column. Notes explain common mistranslations.

## Data and sensors

| 中文 | English | Note |
|---|---|---|
| 遥感影像 | remote sensing imagery / remote sensing images | "imagery" is uncountable |
| 卫星影像 | satellite imagery | |
| 高分辨率影像 | high-resolution imagery | state the resolution, e.g., 0.8 m |
| 多光谱 / 高光谱 | multispectral / hyperspectral | one word, no hyphen |
| 全色波段 | panchromatic band | |
| 合成孔径雷达 | synthetic aperture radar (SAR) | |
| 激光雷达 | LiDAR (light detection and ranging) | |
| 数字高程模型 | digital elevation model (DEM) | |
| 街景影像 | street view imagery (SVI) | Google Street View (GSV) for that product |
| 高分二号 | Gaofen-2 (GF-2) | |
| 哨兵二号 | Sentinel-2 | |

| 波段 | band | |
| 像元 | pixel | |
