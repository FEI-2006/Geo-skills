# Style rules by section

## Abstract (150–300 words; check the journal limit)
Order: problem and gap (1–2 sentences) → objective → data and study area → method → key quantitative results → implication. Every result sentence should carry a number (accuracy, change, coefficient) with its unit. No citations, no undefined abbreviations, no "In this paper". Avoid ending on a vague promise ("provides a reference for…"); end on what the result means.

## Introduction
Move from the broad problem to the specific gap in 3–5 paragraphs. Each paragraph starts with a topic sentence that states its point. State the gap explicitly ("However, few studies have quantified…") and end with numbered objectives or research questions. Cite specific studies for specific claims; do not cite a review for a precise number.

## Study area and data
Give location, size and why the area suits the question. For each dataset: name, provider, spatial resolution, temporal coverage, bands or variables used, access date or version, and licence where relevant (e.g., Google Street View terms of service). A table is often clearer than prose for more than three datasets.

## Methods
Write so that someone could reproduce the work: software and versions, parameters, training/validation/test splits, sample sizes, accuracy metrics and how they were computed. Past tense. Equations are numbered and every symbol is defined right after the equation ("where *d* is…").

## Results
Report, do not interpret (interpretation goes in Discussion unless the journal combines them). Lead each paragraph with the main finding, then the numbers, then the figure or table reference: "Mean GVI decreased from 0.24 to 0.19 (Fig. 4a)." Use the same order of variables as in the methods.

## Discussion
Compare with previous studies by name and number; explain mechanisms with hedged language; state limitations plainly (data gaps, spatial and temporal mismatch, sampling bias, the modifiable areal unit problem); suggest specific future work.

## Conclusion
3–6 sentences or a short numbered list of findings with their key numbers. No new results, no citations.

## Word choice

| Avoid | Prefer |
|---|---|
| utilize | use |
| in order to | to |
| a large number of | many |
| due to the fact that | because |
| has the ability to | can |
| more and more | increasingly |
| obvious / obviously | clear / clearly, or give the number |
| prove | show, indicate, support |
| significant (without a test) | substantial, marked; keep "significant" for statistical tests and give p |
| data is | data are (most geoscience journals) |
| etc. | list the items or use "such as" |

## Figures and tables in text
"Fig. 3" in running text (Elsevier and IEEE); "Figure 3" at the start of a sentence. Tables: "Table 2". Sub-panels: "Fig. 3b" or "Fig. 3(b)" per journal style; be consistent.
